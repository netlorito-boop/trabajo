OBRACERCA — MAPA CON PUNTOS ROJOS

1. Descomprime el ZIP.
2. Abre index.html en un navegador con internet.
3. Los puntos rojos son solicitudes de trabajo. Toca uno para ver detalles y presupuesto.
4. Usa «Publicar trabajo», completa los datos y pulsa «Elegir en el mapa» para poner el punto en el lugar deseado.

IMPORTANTE SOBRE TIEMPO REAL:
Esta versión actualiza el mapa al instante en el navegador donde se publica el trabajo y guarda los anuncios en localStorage. Aún NO sincroniza anuncios entre diferentes teléfonos o computadores. Para tiempo real entre todos los usuarios hay que conectar un backend/base de datos compartida (por ejemplo Supabase Realtime o Firebase), configurar credenciales y desplegar reglas de seguridad. El mapa base usa OpenStreetMap/Leaflet y requiere internet.
